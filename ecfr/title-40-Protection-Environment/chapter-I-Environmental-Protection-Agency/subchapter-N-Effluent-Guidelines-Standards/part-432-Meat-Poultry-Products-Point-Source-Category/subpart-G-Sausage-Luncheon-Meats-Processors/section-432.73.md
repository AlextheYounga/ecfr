##### § 432.73 Effluent limitations attainable by the application of the best available technology economically achievable (BAT).

Except as provided by 40 CFR 125.30 through 125.32, any existing point source subject to this subpart must achieve the following effluent limitations representing the application of BAT: 

(a) Facilities that generate no more than 50 million pounds per year of finished products must achieve the following effluent limitations: 

Effluent Limitations

\[BAT\]
| Regulated   parameter | Maximum daily 1 | Maximum monthly avg. 1 |
| --------------------- | --------------- | ---------------------- |
| Ammonia (as N)        | 8.0             | 4.0                    |
| 1 mg/L (ppm).         |                 |                        |

(b) Facilities that generate more than 50 million pounds per year of finished products must achieve the following effluent limitations: 

Effluent Limitations

\[BAT\]
| Regulated   parameter | Maximum daily 1 | Maximum monthly avg. 1 |
| --------------------- | --------------- | ---------------------- |
| Ammonia (as N)        | 8.0             | 4.0                    |
| Total Nitrogen        | 194             | 134                    |
| 1 mg/L (ppm).         |                 |                        |
