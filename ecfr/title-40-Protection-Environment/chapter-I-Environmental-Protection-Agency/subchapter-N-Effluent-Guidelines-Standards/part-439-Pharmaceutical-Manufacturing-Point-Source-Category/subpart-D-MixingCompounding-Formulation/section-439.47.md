##### § 439.47 Pretreatment standards for new sources (PSNS).

Except as provided in 40 CFR 403.7, any new source subject to this subpart must achieve the following pretreatment standards: 

| Regulated   parameter | Pretreatment standards 1 |
| --------------------- | ------------------------ |
| 1 Acetone             | 20.7                     |
| 2 n-Amyl acetate      | 20.7                     |
| 3 Ethyl acetate       | 20.7                     |
| 4 Isopropyl acetate   | 20.7                     |
| 5 Methylene chloride  | 3.0                      |
| 1 Mg/L (ppm).         |                          |
