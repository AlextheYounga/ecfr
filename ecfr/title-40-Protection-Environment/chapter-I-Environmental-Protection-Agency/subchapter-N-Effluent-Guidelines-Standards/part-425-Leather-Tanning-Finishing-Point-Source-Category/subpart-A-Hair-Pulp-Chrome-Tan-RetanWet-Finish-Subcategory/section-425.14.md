##### § 425.14 New source performance standards (NSPS).

Any new source subject to this subpart must achieve the following new source performance standards (NSPS): 

| Pollutant or pollutant property | NSPS                                    |
| ------------------------------- | --------------------------------------- |
|                                 | Kg/kkg (or lb/1,000 lb) of raw material |
| BOD5                            | 6.0                                     |
| TSS                             | 8.7                                     |
| Oil and grease                  | 2.5                                     |
| Total chromium                  | 0.16                                    |
| pH                              | (1)                                     |
| 1 Within the range 6.0 to 9.0.  |                                         |

\[47 FR 52870, Nov. 23, 1982; 48 FR 30116, June 30, 1983\]
