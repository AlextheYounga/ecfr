##### § 466.45 Pretreatment standards for new sources.

Any new source subject to this subpart which introduces pollutants into a publicly owned treatment works must comply with 40 CFR part 403 and achieve the following pretreatment standards for new sources: 

Subpart D—PSNS
| Pollutant or pollutant property | Maximum for any 1 day                                              | Maximum for monthly average |
| ------------------------------- | ------------------------------------------------------------------ | --------------------------- |
|                                 | Metric units—mg/m2 of area processed or coated                     |                             |
| Chromium                        | 6.23                                                               | 0.46                        |
| Lead                            | 1.69                                                               | 0.13                        |
| Nickel                          | 9.25                                                               | 0.69                        |
| Zinc                            | 17.16                                                              | 1.29                        |
|                                 | English units—pounds per 1 million ft2 of area processed or coated |                             |
| Chromium                        | 1.28                                                               | 0.10                        |
| Lead                            | 0.35                                                               | 0.03                        |
| Nickel                          | 1.90                                                               | 0.14                        |
| Zinc                            | 3.52                                                               | 0.27                        |
