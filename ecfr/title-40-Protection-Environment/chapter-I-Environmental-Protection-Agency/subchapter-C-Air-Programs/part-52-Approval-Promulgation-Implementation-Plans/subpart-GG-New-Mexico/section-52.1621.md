The New Mexico plan was evaluated on the basis of the following classifications: 

| Air quality control region                         | Pollutant |
| -------------------------------------------------- | --------- |
| Albuquerque-Mid-Rio Grande Intrastate              | I         |
| New Mexico Southern Border Intrastate              | IA        |
| El Paso-Las Cruces-Alamogordo Interstate           | I         |
| Four Corners Interstate                            | IA        |
| Northeastern Plains Intrastate                     | III       |
| Pecos-Permian Basin Intrastate                     | III       |
| Southwestern Mountains-Augustine Plains Intrastate | III       |
| Upper Rio Grande Valley Intrastate                 | III       |
